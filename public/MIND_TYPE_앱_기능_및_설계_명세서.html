MIND:TYPE SYSTEM SPECIFICATION VER 2.4 · 2026

MIND:TYPE — 6차원 다면 성격 진단 및 최적 인간관계 추천 시스템

MBTI, 혈액형, 애착유형, 크로노타입 생체시계, 스트레스 대처 방어기제, 고대 4대 기질론의 6개 심리 차원을 결합하여 개인의 입체적 페르소나를 도출하고 최적의 인간관계(연애·우정·협업)와 1:1 케미스트리를 진단하는 플랫폼 명세서입니다.

1. 시스템 개요 및 기술 스택

  • • 프론트엔드 프레임워크: React 19, TypeScript, Vite 8, Motion
  • • 백엔드 런타임: Node.js v22, Express 4, tsx
  • • UI / 디자인: Tailwind CSS v4, Lucide Icons, Warm Minimalist Constitution (Anti-AI Slop, Zero-Pill)
  • • 데이터 시각화: Recharts (6차원 Spider Radar Chart)
  • • AI 모델: Google Gemini 2.5 Flash (@google/genai SDK) 및 자체 규칙 기반 Zero-Token Fallback
  • • 데이터 저장: 브라우저 localStorage 실시간 지속 동기화

2. 6차원 입체 성향 진단 시스템 (총 132문항 5지선답)

단편적인 16가지 MBTI의 한계를 넘어 인간의 다면성을 정밀 입체 프로파일링합니다. 모든 문항은 리커트 5점 척도(1: 전혀 아니다 ~ 5: 매우 그렇다)로 점수화되며 키보드 숫자키 1~5 단축키와 챕터별 점프를 지원합니다.

차원 문항수 세부 지표 구성 산출 방식 및 특징
1. MBTI 인지양식 32문항 EI(8), SN(8), TF(8), JP(8) 축별 점수 합산 비교로 16종 인지 유형 도출
2. 애착유형 관계심리 20문항 관계 불안(10), 친밀감 회피(10) 불안/회피 2차원 회귀 모델로 안정·불안·회피·공포회피 4분면 판정
3. 크로노타입 생체시계 20문항 사자(5), 곰(5), 늑대(5), 돌고래(5) 수면 및 일과 에너지 최적 주기 산출
4. 스트레스 방어기제 20문항 동굴잠수(5), 폭풍수다(5), 행동폭주(5), 이성분석(5) 위기 상황 시 무의식적 회복 프로토콜 판별
5. 4대 원소 고대기질론 20문항 불(5), 물(5), 흙(5), 바람(5) 추진력·공감력·안정성·지적 자유 기질 산출
6. 혈액형 소셜바이브 20문항 A형(5), B형(5), O형(5), AB형(5) 문화적 소셜 바이브와 실제 생체 혈액형 결합

3. 거미줄 레이더 차트 & 성격 핵심 키워드 카드

🕸️ 거미줄 레이더 차트 (Recharts)

외향성, 직관성, 정서 공감, 주간 리듬, 스트레스 수용성, 기질 활동성의 6개 축을 0~100 스케일로 시각화하여 나의 강점과 보완점을 한눈에 보여줍니다.

🏷️ 성격 핵심 키워드 카드

6차원 성향 결합에서 추출한 8개 핵심 해시태그, 나의 3대 초능력(Superpowers), 매력 약점(Blindspot), 최적 시너지 파트너 키워드를 소셜 카드 형태로 제공합니다.

4. 최적 인간관계 매칭 & 1:1 궁합 알고리즘

  • • 소울메이트 3종 매칭: 연애 최강 찰떡궁합(Top 1), 평생 지기(Friendship), 비즈니스 협업 파트너 자동 추천.
  • • 1:1 궁합 정밀 진단서: 종합 궁합 점수(0~100점), 연애·우정·협업·생활리듬 4대 지수, 3대 시너지 포인트, 갈등 주의점 및 화해 가이드.
  • • AI 관계 컨설턴트 (Google Gemini): 구체적인 고민 상황에 대한 실시간 맞춤 솔루션 제공 (API 미연동 시 내장 알고리즘 자동 대체).

5. 초대장 시스템 & 단체 모임 케미 룸

💌 1:1 친구 초대장

초대 링크(`?invite=...`)를 친구에게 공유하면 친구가 검사를 진행하고, 완료 즉시 두 사람의 1:1 궁합 분석서가 자동 연결됩니다.

👥 단체 모임 케미 룸

단톡방에 룸 링크(`?room=...`)를 공유하여 다수가 참여하면 4원소 밸런스, 모임 최적 골든타임, 룸 내 최고 찰떡 콤비 Top 1 및 평화 중재자를 자동 분석합니다.

6. 토큰 최적화 (Zero-Token 모드) 및 클라우드 배포 가이드

  • • 토큰 절약: Google AI Studio 무료 티어(15 RPM / 1,500 RPD) 이용 시 비용 0원이며, API 호출 없이 내장 규칙 엔진만 사용하는 Zero-Token 모드로 100% 무과금 독립 실행 가능.
  • • 배포 명령어: npm run build && npm run start (단일 3000번 포트에서 프론트엔드와 백엔드 통합 서빙).
  • • 클라우드/서버 무중단 실행: PM2 백그라운드 구동(pm2 start server.ts), Docker 컨테이너 지원, Nginx 리버스 프록시 연동 지원.
